# Reference Workflows

## Workflow A — New product with no distribution

1. Intake
2. ICP/JTBD
3. Market terrain
4. Channel scoring
5. Thesis
6. Venue
7. Milestones

## Workflow B — Existing product with weak growth

1. Load KB snapshot
2. Inspect signal history
3. Re-check ICP drift
4. Re-score channels
5. Rebuild thesis if needed

## Workflow C — Strong audience, unclear product fit

1. Identify who is already paying attention
2. Separate audience from buyer
3. Check trust signal and venue fit
4. Test a small, direct offer

## Workflow D — Multiple channels being considered

1. Score them with the same benchmark
2. Choose one primary channel
3. Park the others in the backlog
4. Only add a multiplier after green signal

## Vietnamese note

Workflow mẫu giúp agent biết “đường đi” thay vì chỉ biết rule rời rạc.

## Workflow E — Audit existing VECTOR setup

1. Load the KB.
2. Inspect the active mode and routing path.
3. Check for schema drift.
4. Check for duplicated or conflicting instructions.
5. Check whether every phase emits an artifact.
6. Patch the weakest link first.

## Workflow F — Research before committing to a channel

1. Run research mode.
2. Build the competitor and substitute map.
3. Classify market density.
4. Pull the strongest evidence into the channel scorecard.
5. Only then commit to a primary channel.

## Workflow G — Copy generation for launch

1. Lock the thesis.
2. Identify the venue.
3. Generate a message matrix.
4. Produce DM copy, post copy, headline copy, and CTA variants.
5. Send the best variant to testing.
6. Track response and revise the copy pack.

## Workflow H — Recovery after poor signal

1. Freeze scaling.
2. Re-read the current KPIs.
3. Classify the failure mode.
4. Re-check ICP drift.
5. Re-score channel fit.
6. Adjust venue or offer architecture.
7. Resume only when the new signal is clear.
