# ARTIFACT BLUEPRINTS v2.0

Canonical output templates cho mỗi VECTOR phase. Dùng như reference để agent và founder đồng thuận về "xong" nghĩa là gì — trước khi chuyển bước.

---

## Phase 0 — Intake Summary

```text
INTAKE SUMMARY
Product:                  [một câu, không jargon]
Problem:                  [một câu — pain, không phải feature]
Target persona:           [role + context — hypothesis only]
Why now:                  [timing trigger hoặc market pressure]
Evidence level:           [observed / inferred / speculative]
Constraint:               [time / money / access / credibility]
Founder edge:             [insider knowledge / network / experience / none stated]
Known channels/communities: [list hoặc "unknown"]
Early network signals:    [warm contacts trong target community? y/n + context]
Riskiest assumption:      [đặt tên rõ ràng]
```

## Phase 1 — ICP Card

```text
JOB STATEMENT:
Khi [situation], [target user] muốn [job], để họ có thể [outcome].

ICP CARD:
Who:            [role, company size, maturity]
Core problem:   [specific pain — không phải category]
Trigger moment: [event nào khiến họ act now]
Watering holes: [nơi họ đang congregate]
WTP signal:     [evidence về willingness to pay]

4 FORCES MAP:
Push (đang đẩy họ đi):  [pain, frustration cụ thể]
Pull (đang kéo họ đến): [outcome họ muốn, picture được]
Anxiety (cản switch):   [fear cụ thể — switching cost, career risk, ROI unclear]
Habit (inertia):        [workaround hiện tại, "tạm ổn" belief]

EVIDENCE TAGS:
Who:            [observed / inferred / benchmarked / speculative]
Core problem:   [observed / inferred / benchmarked / speculative]
Trigger moment: [observed / inferred / benchmarked / speculative]
WTP signal:     [observed / inferred / benchmarked / speculative]
4 Forces:       [observed / inferred / benchmarked / speculative]

RISKIEST ASSUMPTION: [một câu]
CONFIDENCE:          [low / medium / high]
DRIFT STATUS:        [stable / drifting — mô tả]
TOP UNKNOWN:         [điều gì sẽ thay đổi card này nhất nếu biết]
NEXT EXPERIMENT:     [test nhỏ nhất để reduce uncertainty]
```

## Phase 3–4 — Channel Scorecard (Stage-Weighted)

```text
CHANNEL: [tên]
STAGE:   [0→1 / 1→10 / 10→100]

FOUNDER EDGE AUDIT:
  Network/audience present:      [Yes/No]
  Track record at this channel:  [Yes/No]
  Credibility recognizable:      [Yes/No]
  Speed advantage:               [Yes/No]
  Warm door opener:              [Yes/No]
  Builder Advantage Score:       [X/5]

SCORING (Stage weights applied):
  ICP Match:         [1–5] × [weight] = [weighted] — [lý do]
  Builder Advantage: [X/5 từ audit] × [weight] = [weighted]
  Speed to Signal:   [1–5] × [weight] = [weighted] — [lý do]
  Cost to Test:      [1–5] × [weight] = [weighted] — [lý do]
  Scalability:       [1–5] × [weight] = [weighted] — [lý do]

  Weighted raw:  [X / max]
  Normalized:    [X / 100]
  Threshold:     [weak / promising / strong]

WHY THIS CHANNEL:  [evidence + stage grounded]
FIRST TEST:        [time-boxed, concrete experiment]
FAILURE SIGNAL:    [dấu hiệu cụ thể cho thấy không work]
WHY NOT OTHERS:    [mỗi channel bị loại + lý do ngắn]
```

## Phase 5 — Thesis Card

```text
PRODUCT:             [tên]
ICP:                 [một câu — từ ICP card]
STAGE:               [0→1 / 1→10 / 10→100]
RISKIEST ASSUMPTION: [một câu]

PRIMARY CHANNEL:     [tên — từ channel scorecard]
CHANNEL SCORE:       [X/100]
WHY THIS CHANNEL:    [evidence + stage grounded]
ANGLE:               [hook hoặc entry point cụ thể]
UNFAIR ADVANTAGE:    [điều gì làm founder credible ở channel này]

GROWTH MULTIPLIER:   [Type A / B / C / D — hoặc "not yet"]
UNLOCK CONDITION:    [điều gì phải đúng trước khi add multiplier]

REVERSIBILITY:       [khó / medium / dễ — tại sao]
CONFIDENCE:          [low / medium / high — với lý do]

EVIDENCE USED:       [list key evidence]
ALTERNATIVES REJECTED: [channels đã xem xét + lý do loại]

NOTE: Thesis card KHÔNG chứa venue, product architecture, trust signal, 
      primary CTA, hay ICP drift check — những thứ này thuộc Venue card.
```

## Phase 6 — Venue Card

```text
SALES VENUE:
  Name:    [loại venue]
  Why:     [tại sao fit channel behavior + buyer trust level]
  Format:  [cụ thể: DM → link / community post → reply / v.v.]

PRODUCT ARCHITECTURE:
  Entry:  [format] — [price] — [purpose + outcome cụ thể]
  Core:   [format] — [price] — [purpose]
  Upsell: [format] — [price] — [purpose / "locked — pending signal"]

TRUST SIGNAL NEEDED:
  Level:    [high / medium / low — từ ICP anxiety]
  Required: [cụ thể — loại và số lượng]
  Status:   [có rồi / cần build / không cần ở stage này]

VENUE RISK:
  Main risk:            [điều likely nhất break launch]
  Failure mode:         [dấu hiệu cụ thể của failure]
  Mitigation:           [cách reduce risk]

ICP DRIFT CHECK:
  What counts as drift: [dấu hiệu cụ thể — sai role / company size / trigger]
  What to do:           [tighten ICP / channel filter / không thay venue]

PRIMARY CTA:
  One action only: [động từ + outcome cụ thể]
```

## Loop-Back Quick Reference

Khi Signal = Red, dùng bảng này để route về đúng phase:

| Drift Type | Return Phase | Artifact cần update |
|---|---|---|
| wrong ICP | Phase 1 — ICP Card | ICP card, evidence tags |
| wrong channel | Phase 3–4 — Channel Scorecard | Re-score candidates |
| wrong angle | Phase 5 — Thesis Card (angle field only) | Thesis card — angle |
| wrong venue | Phase 6 — Venue Card | Venue card |
| weak trust signal | Phase 6 — Venue Card (trust signal only) | Venue card — trust signal |
| too much scope | Phase 6 — Venue Card (entry offer) | Venue card — entry offer |
| too much noise | Phase 3–4 — Channel Scorecard | Re-score với less noisy candidates |
