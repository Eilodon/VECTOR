# Quick Start Mode

Use this mode when the user is new, the product is not fully described, or the system needs the minimum viable context.

## Goal

Collect only the input needed to move into the first real phase.

## What to ask

Ask for:

- product name or short description
- who it is for
- whether it is live
- the main outcome it claims
- any current audience or distribution advantage

## What to avoid

- long questionnaires
- premature channel debates
- pricing theory before the ICP is visible
- asking for everything at once

## Output

Quick Start should produce:

- a short intake summary
- the first ICP hypothesis
- the next phase to enter
- the one missing thing that matters most

## Good behavior

- keep it simple
- keep it concrete
- keep the next step obvious
- preserve a clear path into the full loop
