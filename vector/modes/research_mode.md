# Research Mode

Use this mode when the system needs evidence before a decision.

## When to use

Use Research Mode when the user wants:

- competitor clarity
- substitute mapping
- channel evidence
- trust signal analysis
- a more accurate ICP hypothesis
- support for a thesis that is still shaky

## Inputs

Research Mode should start from:

- product summary
- ICP hypothesis
- current phase
- existing experiments
- known competitors or workarounds
- current constraints

## Outputs

Research Mode should produce:

- evidence memo
- source table or note set
- what is known
- what is still uncertain
- one recommended next experiment
- any drift warnings

## Default workflow

1. Restate the question in plain language.
2. Separate facts from assumptions.
3. Group evidence into signal, noise, and missing data.
4. Identify what would change the decision.
5. End with the smallest next experiment.
6. Write the result back into the ledger or KB.

## Guardrails

- Do not let research become endless browsing.
- Do not convert weak evidence into strong claims.
- Do not change the thesis unless the evidence actually supports it.
- Do not skip the next action.

## Good research output

A good memo answers:

- what the market says
- what the buyer behavior suggests
- what the channel evidence implies
- what we still need to verify
