# Copy Mode v2.0.0

Use this mode when the thesis and venue are already locked and the task is to turn them into launch-ready messages.

> **v2.0.0 guard:** Before writing any copy, run the Objection Identification Protocol (see `skills/salescopy/SKILL.md`) to map primary objection → copy job from 4 Forces. Copy written without this step is not considered complete.

## When to use

Use Copy Mode only after the system can answer these questions clearly:

- Who is the exact ICP?
- What is the one primary channel?
- What venue fits that channel’s trust behavior?
- What single action should the buyer take?

If those answers are still moving, return to thesis or venue work first.

## Outputs

Copy Mode should produce all of the following, not just a paragraph of copy:

- headline variants
- subheadline variants
- DM variants
- email variants
- CTA variants
- message matrix
- proof notes
- simple test plan

## Default workflow

1. Read the ICP, thesis, and venue cards.
2. Run Objection Identification Protocol (4 Forces → objection_map). **Required in v2.0.0.**
3. Restate the thesis in one sentence.
4. Identify the one action the asset should drive.
5. Draft a matrix of variants by purpose (curiosity/pain/outcome/trust/urgency).
6. Check that every variant still matches the venue.
7. Reject anything that introduces new positioning.
8. Finish with a tiny test plan that names what success looks like.
9. Run QA checklist (7 items) before marking as done.

## Guardrails

- Do not invent positioning that conflicts with the current thesis.
- Do not add multiple CTAs to a single primary asset.
- Do not use copy to broaden the ICP.
- Do not write “clever” copy if clarity is still weak.
- Do not treat a draft as a strategic decision.

## Minimum good output

A useful copy pack includes:

- `objection_map`: primary objection + type (anxiety/habit) + copy job + placement
- one clear primary headline
- one supporting proof line
- one CTA
- one fallback CTA
- one objection-handling line
- one test plan with a measurable check
- QA checklist (7 items — từ salescopy skill)

## Example

```text
Primary headline: Find the channel that actually fits your ICP.
Subheadline: VECTOR maps your market, scores your options, and locks the first move.
CTA: Book the teardown
Proof line: Built for solo founders who need signal, not guesswork.
Test plan: send 3 variants to 10 qualified buyers and track reply quality.
```
