# Antigravity Adapter

## Best surface

Antigravity is promising when VECTOR needs an agent-first development environment with editor, terminal, and browser available in one surface.

## Recommended setup

- Keep VECTOR portable: schemas, orchestrator, KB, and MCP runtime should remain repo-based.
- Treat Antigravity as an execution shell, not the source of GTM truth.
- Start with repo instructions plus MCP-backed tasks before assuming deeper native integration.

## VECTOR mapping

- Orchestrator → repo task framing
- MCP runtime → GTM tool backend
- KB → stable repo artifact

## Failure mode to avoid

Do not market this adapter as production-ready until the public integration surface is more mature and smoke-tested against VECTOR.
