# Edge Cases

## 1) Product exists, ICP unclear

Action: run ICP discovery before channel scoring.

## 2) Product not launched yet

Action: run discovery and market mapping only. Do not recommend scaling.

## 3) Responses are positive but no sale

Action: inspect venue, trust signal, pricing, and offer shape.

## 4) Channel has traffic but no conversions

Action: separate interest from intent.

## 5) One respondent is very excited but clearly non-ICP

Action: treat it as noise unless the evidence repeats.

## 6) User insists on “doing everything”

Action: hold the line on the 0→1 single-channel rule.

## 7) User already has a strong audience

Action: assess whether advocacy or referral loops are the true multiplier.

## Edge case — the user already has revenue but no clarity

Treat this as a fast-path toward market, channel, venue, and signal rather than a full discovery reset.

## Edge case — the user wants to compare two equally strong channels

Score both, but choose only one primary channel for the first commitment window.

## Edge case — the user wants VECTOR to produce copy before strategy

Only do this if the thesis is already locked. Otherwise the copy is likely to become premature optimization.

## v1.6 applied edge case — strong interest, weak conversion

If a channel produces attention but not purchase intent, do not celebrate the channel yet. Inspect venue fit and trust signal before changing the thesis.

## v1.6 applied edge case — copy request with missing thesis

If the user wants copy before the thesis is locked, route to research or thesis repair first, unless placeholders are explicitly requested.
